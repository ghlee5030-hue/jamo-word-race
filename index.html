정답 단어를 자음과 모음 5개 또는 6개 조각으로 맞히는 한글 단어 배틀입니다. 사전에 있는 표제어 조합만 제출할 수 있어요.

  • 혼자 하기: 화면 키보드나 실제 키보드로 낱자를 넣고 입력을 눌러 색상 힌트를 확인하세요.
  • 키보드 이동: 아래쪽의 키보드 이동 바를 누른 채 위아래로 끌면 화면 키보드 위치를 조절할 수 있어요.
  • 키보드 방식: 두벌식과 천지인 중 편한 방식을 선택할 수 있습니다. 선택한 방식은 다음에도 유지돼요.
  • 친구와 대결: 방 만들기를 누르면 대기방이 열립니다. 공유 링크 복사를 눌러 친구에게 보내세요.
  • 방 코드 입장: 친구에게 방 코드를 받았다면 방 코드 칸에 입력한 뒤 입장을 누르면 같은 방에 들어갑니다.
